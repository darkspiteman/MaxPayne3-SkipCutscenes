# MP3SkipCutscenes — пропуск кат-сцен в Max Payne 3 (Steam и Rockstar Games Launcher)

ASI-плагин для `MaxPayne3.exe` (PC, 32 бита). Сделан и проверен на 1.0.0.276 (Steam).

Подходит и для версии Rockstar Games Launcher: в моде нет ничего привязанного к Steam, нужные места в
`MaxPayne3.exe` он находит по сигнатурам. На версии Rockstar Games Launcher мод пока **не проверялся** —
после первого запуска посмотрите лог (см. шаг 7 установки).

- **Space** (или другая клавиша из `.ini`) пропускает кат-сцены наравне со штатной кнопкой пропуска.
- **Одно нажатие — до геймплея**: всё, что начинается в течение 2 секунд после пропущенной сцены (следующая
  сцена, transition-ролик), пропускается автоматически (`ChainWindowMs`).
- Сцены, пропуск которых **заблокирован скриптами**: мод сначала принудительно догружает уровень
  (`LOAD_ALL_OBJECTS_NOW`). Обычно после этого скрипты сами снимают блокировку, и сцена сразу обрывается штатным
  пропуском. Если блокировка остаётся — сцена перематывается к последней секунде и заканчивается сама
  (`LockedMode=1`) либо обрывается штатным пропуском, как в старом скипере (`LockedMode=2`).
- **Transition-ролики** между главами (Bink, `s_*.bik`) пока **не пропускаются**: их ~6 секунд держат скрипты
  игры (изучается). Мод только догружает уровень, пока ролик идёт.
- **Килкамы** (bullet camera) обрываются той же клавишей (`SkipKillCams`).
- Пишет диагностический лог `MP3SkipCutscenes.log`.
- Файлы игры на диске не изменяются. Steam, Rockstar Games Launcher и защита (`MTLX.dll`) не затрагиваются.

> **Статус проверки.** Проверено в игре (Steam, 1.0.0.276): все сигнатуры найдены, пропуск обычных и
> заблокированных сцен, догрузка перед пропуском, цепочки «одно нажатие до геймплея», обрыв килкамов
> (постановочные килкамы защищены первые 1,5 с). Версия Rockstar Games Launcher не проверялась.
> Подробнее — [docs/TESTING.md](docs/TESTING.md).

### Почему старый скипер роняет игру

Старый `SkipCutscenes.asi` каждый кадр вызывает `CUTSCENE_ENABLE_SKIP(1)` и `SET_TRANSITION_MOVIE_SKIPPABLE(1)`,
то есть просто снимает блокировку. Сцена обрывается, пока уровень ещё не подгружен, — отсюда вылеты, смерть
героя и «надо подождать и потом пропускать». Этот мод перед пропуском догружает уровень сам.

## Как это работает

Техника взята из открытого [MaxPayne3.FusionFix](https://github.com/ThirteenAG/MaxPayne3.FusionFix)
(модуль `cutsceneskip`, GPL-3.0) и реализована заново без зависимостей. Подробности — в
[docs/RESEARCH.md](docs/RESEARCH.md).

1. Мод ждёт, пока игра сама расшифрует свой код и создаст окно, затем ищет нужные места по сигнатурам.
   Каждый найденный адрес проверяется; если что-то не сходится — соответствующая функция отключается, игра
   остаётся нетронутой, причина пишется в лог.
2. Патчи ставятся только в памяти процесса, при приостановленных остальных потоках.
3. Скриптовая функция `CUTSCENE_ENABLE_SKIP(FALSE)` перехватывается: подсказка пропуска остаётся на экране,
   а то, что сцена «заблокирована», мод запоминает и при нажатии делает перемотку к концу вместо обрыва сцены.

Если установлен FusionFix, мод отключается сам (у FusionFix своя такая же функция, вместе они конфликтуют).

## Установка (Steam или Rockstar Games Launcher)

Нужен ASI-загрузчик — DLL, которую игра загружает сама и которая подгружает `*.asi`.

1. Закройте игру.
2. Откройте папку игры: Steam → Библиотека → Max Payne 3 → ⚙ → Управление → Просмотреть локальные файлы →
   папка `Max Payne 3` (в ней лежит `MaxPayne3.exe`). Обычно это
   `C:\Program Files (x86)\Steam\steamapps\common\Max Payne 3\Max Payne 3`.
   Rockstar Games Launcher: Настройки → Мои установленные игры → Max Payne 3 → Открыть (обычно
   `C:\Program Files\Rockstar Games\Max Payne 3`).
3. Скопируйте туда из папки `dist\`:
   - `MP3SkipCutscenes.asi`
   - `MP3SkipCutscenes.ini` (необязательно — без него действуют значения по умолчанию)
4. ASI-загрузчик — один из вариантов:
   - **уже есть** `dinput8.dll` (ASI Loader от Unknown Modder или Ultimate ASI Loader) — ничего делать не нужно;
   - **нет загрузчика** — скопируйте `dist\loader\dinput8.dll` (собран из `loader/dinput8.cpp` этого проекта).
     Не заменяйте им уже существующий `dinput8.dll`, не сделав копию.
5. Если в папке игры есть старый `SkipCutscenes.asi` (плагин ScriptHook) — уберите его (см. «Удаление»),
   вместе они работать не должны.
6. Запустите игру как обычно (через Steam или Rockstar Games Launcher).
7. Проверьте `MP3SkipCutscenes.log` рядом с `MaxPayne3.exe`: в конце должно быть `hooks installed` и `ready`.

### Управление

| Действие | Клавиша |
|---|---|
| Пропустить кат-сцену / ролик | **Space** или штатная кнопка пропуска игры |

Клавиша меняется в `MP3SkipCutscenes.ini` (`SkipKey`, код виртуальной клавиши; `0` — только штатная кнопка).
Пропуск срабатывает после первой секунды кат-сцены (так работает сама игра).

## Удаление

1. Закройте игру.
2. Удалите из папки игры `MP3SkipCutscenes.asi`, `MP3SkipCutscenes.ini`, `MP3SkipCutscenes.log`.
3. Если ставили `dinput8.dll` из этого проекта и другие ASI-моды не нужны — удалите `dinput8.dll` и
   `MP3AsiLoader.log`.

Больше мод нигде ничего не оставляет: реестр, сохранения и файлы игры не изменяются.

### Восстановление оригинальной игры

Оригинальные файлы мод не трогает, поэтому после удаления файлов выше игра полностью оригинальна. Чтобы убрать
вообще всё стороннее и проверить целостность:

1. Удалите из папки игры файлы, которых нет в оригинале: `dinput8.dll`, `*.asi`, `asiloader.log`,
   `ScriptHook.log`, `ScriptHook.dll`, `MP3AsiLoader.log`, `MP3SkipCutscenes.*`.
2. Steam → Библиотека → Max Payne 3 → ⚙ → Свойства → Установленные файлы → **Проверить целостность файлов игры**.

## Сборка

Требуется 32-битный компилятор C++17 и CMake ≥ 3.20. Проверенный набор (ставится через winget):

```
winget install Kitware.CMake
winget install Ninja-build.Ninja
winget install MartinStorsjo.LLVM-MinGW.UCRT
```

Сборка Release и запуск тестов:

```
powershell -ExecutionPolicy Bypass -File build.ps1
```

Результат: `build\MP3SkipCutscenes.asi`, `build\loader\dinput8.dll`. Вручную:

```
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DCMAKE_TOOLCHAIN_FILE=cmake/toolchain-llvm-mingw-i686.cmake -DLLVM_MINGW_ROOT=<папка llvm-mingw>
cmake --build build
ctest --test-dir build --output-on-failure
```

Проект также рассчитан на MSVC (`cmake -A Win32`), но этим компилятором **не собирался и не проверялся**.

Собранные файлы: PE32 x86, зависят только от `KERNEL32.dll`, `USER32.dll` и UCRT
(`api-ms-win-crt-*.dll`, входит в Windows 10/11). Ничего не экспортируют (кроме пяти функций-переходников в
`dinput8.dll`).

## Известные ограничения

- Проверен только `MaxPayne3.exe` 1.0.0.276 (Steam). Версия Rockstar Games Launcher должна работать (поиск по
  сигнатурам), но не проверялась. На отличающемся exe мод ничего не сделает, если сигнатуры не совпадут, и
  напишет об этом в лог.
- Transition-ролики между главами идут свои ~6 секунд.
- Сцены, которые скрипты не разблокируют даже после догрузки, при `LockedMode=1` доигрывают последнюю секунду
  (`LockedTailFrames`). `LockedMode=2` быстрее, но это тот же обрыв, что у старого скипера (только после догрузки).
- Для спидрана: на speedrun.com в зачёт может допускаться только их собственный скипер — уточните правила
  категории.
- Во время догрузки (`LOAD_ALL_OBJECTS_NOW`) игра на короткое время замирает — это ожидаемо.
- Пропуск возможен после первой секунды кат-сцены.
- Заставки при запуске игры (логотипы, `fe_intro.bik`) мод не пропускает.
- Space на transition-роликах работает через дополнительные места проверки кнопки пропуска, найденные по
  сигнатуре; если таких мест в игре не окажется, ролики пропускаются только штатной кнопкой (в логу будет
  `no other skip checks found`).
- Несовместим с одновременной работой FusionFix (отключается сам) и со старым `SkipCutscenes.asi`.
- Мод рассчитан на одиночную игру; в мультиплеере не проверялся и не предназначен для него.
