# Проверка: что подтверждено, что нет, план теста в игре

## Проверено автоматически (без игры)

Запуск: `powershell -ExecutionPolicy Bypass -File build.ps1` (сборка + `ctest`).

| Тест | Что подтверждает |
|---|---|
| `hooks` (`tests/test_hooks.cpp`, 43 проверки) | разбор и поиск сигнатур (уникальность, подстановочные байты, границы); перенаправление `call`; перехват входа в функцию с трамплином; встраиваемый хук 7-байтной инструкции; отказ при изменившихся байтах; установка хука, пока другой поток непрерывно вызывает функцию |
| `simulated_game` (`tests/test_sim.cpp`, 45 проверок) | весь боевой код мода (`skip.cpp`) на поддельной «игре» с теми же сигнатурами и раскладкой вызовов: установка, покадровый хук, хук `CUTSCENE_ENABLE_SKIP`, штатный пропуск, пропуск по Space, удержание клавиши, заблокированная сцена (перемотка, звук, `LOAD_ALL_OBJECTS_NOW` дважды), повторное нажатие, пауза, мультиплеерный запрет, сцена у самого конца, сброс блокировки на следующей сцене, transition-ролик (ожидание стабильных кадров, пауза, Space) |
| `load_in_foreign_process` | DLL загружается в посторонний процесс, ничего не трогает, пишет лог |
| `asi_loader` | прокси `dinput8.dll`: пять экспортов, настоящий `DirectInput8Create` через него работает, `.asi` загружается не в `DllMain` |

Также проверено: `MP3SkipCutscenes.asi` — PE32 **x86**, ASLR/DEP включены, импорт только `KERNEL32`, `USER32`,
UCRT; экспортов нет.

**Чего эти тесты не доказывают:** что настоящая игра 1.0.0.276 устроена так, как предполагает мод. Симулятор
построен по тем же предположениям, что и мод (сигнатуры и смещения из исходников FusionFix).

## План проверки в игре

Подготовка: установить по `README.md`, в `MP3SkipCutscenes.ini` поставить `LogLevel=2`.
После **каждого** шага смотреть `MP3SkipCutscenes.log` в папке игры.

### Шаг 1. Запуск (2 минуты)

1. Запустить игру через Steam, дойти до главного меню, выйти.
2. В логе ожидается:
   - `host: ...MaxPayne3.exe, version 1.0.0.276`
   - блок `signatures:` — **все строки `ok`**, у `skip flag resets` `matches: 2`;
   - `features: per-frame hook yes, natives yes, extra key in cutscenes yes, script-locked cutscenes yes, transition movies yes`;
   - `hooks installed (N patches, attempt 1)`, `ready`, `first game frame`, `native hook: CUTSCENE_ENABLE_SKIP ... (game code ...)`.
3. Если какая-то строка `NOT FOUND` / `BAD` / `NO` — мод отключил эту часть; пришлите лог, сигнатуру нужно
   уточнять. Если игра вылетела — пришлите лог и уберите `.asi` (см. «Откат»).

### Шаг 2. Обычная кат-сцена

1. Сюжет → новая игра (или глава 1). На первой кат-сцене дождаться подсказки пропуска, нажать **Space**.
2. Ожидается: сцена пропущена так же, как штатной кнопкой. В логе: `cutscene: skip pressed (extra key, VK 32)`.
3. Повторить на другой сцене штатной кнопкой: `cutscene: skip pressed (game's skip button)`.

### Шаг 3. Заблокированная кат-сцена

1. Найти сцену, где игра пишет «STILL LOADING» / не даёт пропустить (начало главы, переход между участками).
   В логе перед ней должно появиться `cutscene: scripts LOCK the skip (CUTSCENE_ENABLE_SKIP(0))`.
2. Нажать Space. Ожидается: сцена перескакивает к последним ~3 секундам, короткая пауза на загрузку,
   сцена заканчивается, управление возвращается, уровень цел (нет пустоты/провалов под текстуры).
3. В логе: `locked cutscene: frame A -> B ...`, затем `LOAD_ALL_OBJECTS_NOW ... took N ms`,
   затем `locked cutscene: finished ...`.
4. Плохие признаки: `implausible timeline`, `the seek ... didn't complete in 60 s`, чёрный экран, зависание.

### Шаг 4. Transition-ролик

1. Дойти до конца главы (или выбрать главу в меню — перед ней играет ролик `s_*.bik`).
2. В логе: `movie: transition movie started (skippable 0, streaming requests N)`, позже
   `movie: made skippable ... ms after its start`.
3. После этой строки нажать Space, затем (если не сработало) штатную кнопку. Записать, что сработало.
4. Ожидается: ролик прерывается, глава начинается нормально.

### Шаг 5. Устойчивость

- Умереть сразу после пропущенной сцены, дождаться перезагрузки чекпойнта, снова пропустить.
- Пропустить подряд 5–10 сцен в одной главе, включая сцену перед боссом (глава с Беккером — известное
  проблемное место старого мода).
- Пройти переход между двумя главами с пропуском всего подряд; проверить, что прогресс сохранился
  (выйти в меню → «Продолжить»).
- Нажимать Space в меню паузы и в обычном геймплее: мод не должен ни на что влиять вне сцен.

### Откат

Закрыть игру и удалить `MP3SkipCutscenes.asi` из папки игры (или поставить `Enabled=0` в `.ini`).
Файлы игры мод не меняет, поэтому больше ничего восстанавливать не нужно.

## Что смотреть в логе 0.2

- `locked cutscene: LOAD_ALL_OBJECTS_NOW ...` → `scripts allow the skip` → `ending it with the game's own skip` —
  быстрый путь сработал.
- `still locked N frames after loading - moving it to its end` — сцена из тех, что скрипты не разблокируют.
- `cutscene: started ... right after a skip, skipping it too` — сработала цепочка.
- `movie: scripts set skippable = ...` и `movie:   skip check returning to RVA ... ran N times` — диагностика
  роликов: по ней видно, сбрасывают ли скрипты флаг и какие проверки кнопки реально работают во время ролика.
- `kill cam: ended` — килкам оборван.
